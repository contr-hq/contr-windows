## Install

Download `Contr.App-win-x64-Setup.exe`, or `Contr.App-win-x64.msi` for a managed install. Each file carries a GitHub
build attestation (`gh attestation verify <file> --repo contr-hq/contr-windows`) and is listed in `SHA256SUMS`.

Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/)
