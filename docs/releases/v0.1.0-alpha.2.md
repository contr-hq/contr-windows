The first preview of Contr for Windows, a desktop app for building and running containers on a Docker-compatible
engine in WSL 2. It is an early build for trying Contr out; expect rough edges.

## What's new

This is the app's first release. It sets up the Contr core on first run and manages it from then on.

- **First-run setup:** checks this PC, installs WSL when it is missing (one administrator prompt, and Windows may ask
  you to restart), sets up the engine, installs the command-line tools, lets your own WSL distributions use the
  engine, and starts Contr when you sign in if you want it to.
- **Containers:** grouped by Compose project, each with its logs, details, a terminal and live stats. Run containers
  from an image, start, stop, restart, pause, resume, kill, rename and delete them.
- **Images, volumes and networks:** pull images with per-layer progress, create and delete volumes, remove unused
  images and volumes, and see every container on a network and connect or disconnect one.
- **Compose:** up, pull, restart, stop and down a project and watch Compose's output, restart a single service, read
  the project's logs together, and add a project from its `compose.yaml`.
- **Kubernetes:** a single-node k3s cluster on the engine. Turn it on and off, choose its version and whether Traefik
  runs, make it kubectl's current context, copy images from the engine into it, and reset it.
- **Settings:** the proxy, also for new containers and builds; trusting the certificates Windows trusts; a registry
  mirror; the engine's `daemon.json`, checked by the engine before it is saved; starting the engine with Contr; the
  standard Docker pipe; and the update check. Settings your organization manages show as managed.
- **Troubleshoot:** what keeps the engine from working and the fixes Contr offers, the app's log, a diagnostics zip
  for support with credentials and personal details replaced, and resetting the engine, Kubernetes or everything.
- The tray keeps Contr at hand while its window is closed, and the status bar shows the engine's state, CPU, memory
  and disk.

## What it includes

[Contr core 0.1.0-alpha.2](https://github.com/contr-hq/contr/releases/tag/v0.1.0-alpha.2): `contrd.exe`, `contr.exe`,
the engine's WSL images with Moby 29.9.1, and Docker CLI 29.9.1, Compose 5.6.0, Buildx 0.38.0 and kubectl 1.37.1.

## Install

Contr needs Windows 11, or Windows 10 22H2 (untested so far), on x64.

Download `Contr.App-win-x64-Setup.exe`, or `Contr.App-win-x64.msi` for a managed install. Setup installs Contr for
your user, without administrator rights, in `%LOCALAPPDATA%\Contr.App`. Each file carries a GitHub build attestation
and is listed in `SHA256SUMS`. To check a download before you run it:

```powershell
gh attestation verify .\Contr.App-win-x64-Setup.exe --repo contr-hq/contr-windows
(Get-FileHash .\Contr.App-win-x64-Setup.exe -Algorithm SHA256).Hash
```

The hash must match the file's line in `SHA256SUMS`.

Contr checks GitHub once a day for new releases and shows them in Settings › Updates. Turn the check off there or
during setup.

Uninstalling the app leaves the engine and your images, containers and volumes in place: the WSL distributions
`contr` and `contr-data`, and the files and command-line tools in `%LOCALAPPDATA%\Contr`.

## Known limitations

- The installer, the app and the core are not code-signed yet. Windows SmartScreen warns before Setup runs (choose
  **More info**, then **Run anyway**), and Smart App Control, when it is on, may block them. Check the download as
  above first.
- Contr doesn't update itself yet. When Settings › Updates shows a newer release, download it from its release page.
- The engine's CPU, memory and disk limits can't be changed yet.
- Builds are for x64 only.
- Installing WSL downloads it from Microsoft.
