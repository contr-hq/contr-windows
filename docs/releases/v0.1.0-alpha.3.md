The second preview of Contr for Windows, a desktop app for building and running containers on a Docker-compatible
engine in WSL 2. It is an early build for trying Contr out; expect rough edges.

## Before you upgrade from 0.1.0-alpha.2

- **If you installed with `Setup.exe`:** quit Contr from its tray icon, then run the new `Setup.exe`.
- **If you installed with the MSI:**
  1. Start the engine in Contr and leave it running.
  2. Install the new MSI.
  3. Quit Contr from its tray icon and start it again.

  As the old MSI is replaced, it deletes most of `%LOCALAPPDATA%\Contr`. Only files in use survive. With the engine
  running, your images, containers and volumes are kept, but the command-line tools and Contr's settings are not.
  Afterwards:
  - install the tools again with **Repair the tools** in Settings › General;
  - turn **Start the engine whenever Contr starts** back on.
- **Don't uninstall a 0.1.0-alpha.1 or 0.1.0-alpha.2 MSI install while the engine is stopped.** Its uninstaller would
  delete the engine's disks along with your images, containers and volumes.

This version's MSI fixes these problems for every later upgrade and uninstall.

## What's new

- **Work that keeps going:** pulls, Compose actions, copying images into Kubernetes, fixes, engine resets and
  diagnostics bundles run in the Contr core. They keep going when you switch pages, close the window or quit Contr.
  - The activity view in the status bar lists running and finished work, with its progress, and cancels it.
  - It saves a finished diagnostics bundle, and pages show their work again when you come back.
  - Windows notifies you when work finishes while Contr is hidden.
  - Work started from the `contr` command line shows there too.
- **Published ports:** a port a container publishes listens on Windows at the address Docker reports: `-p 8080:80` on
  every interface, `-p 127.0.0.1:8080:80` on this computer only. Other computers reach it once an administrator allows
  Contr daemon in Windows Firewall.
- **A new look:** a darker, muted slate theme and app icon. **Accent color** in Settings › General switches between
  Contr's accent and Windows'.
- **Installing and upgrading:** an MSI upgrade replaces the previous version and keeps the engine's data, and
  uninstalling keeps it too. Contr quits when an installer, signing out or another program asks it to close, starts
  again after an upgrade, and starts no daemon while Windows Installer runs.
- **Fixes:**
  - The Compose page no longer freezes when Compose prints the same line twice.
  - Quitting Contr no longer ends in a crash report.
  - Pages free their memory when you leave them.
  - Contr connects only to a daemon that runs as you.

## What it includes

[Contr core 0.1.0-alpha.3](https://github.com/contr-hq/contr/releases/tag/v0.1.0-alpha.3): `contrd.exe`, `contr.exe`,
the engine's WSL images with Moby 29.9.1, and Docker CLI 29.9.1, Compose 5.6.0, Buildx 0.38.0 and kubectl 1.37.1.

## Install

Contr needs Windows 11, or Windows 10 22H2 (untested so far), on x64.

Download `Contr.App-win-x64-Setup.exe`, or `Contr.App-win-x64.msi` for a managed install. Setup installs Contr for
your user, without administrator rights, in `%LOCALAPPDATA%\Contr.App`. Each file carries a GitHub build attestation
and is listed in `SHA256SUMS`. To check a download before you run it:

```powershell
gh attestation verify .\Contr.App-win-x64-Setup.exe --repo contr-hq/contr-windows
(Get-FileHash .\Contr.App-win-x64-Setup.exe -Algorithm SHA256).Hash
```

The hash must match the file's line in `SHA256SUMS`.

Contr checks GitHub once a day for new releases and shows them in Settings › Updates. Turn the check off there or
during setup.

Uninstalling the app leaves the engine and your images, containers and volumes in place: the WSL distributions
`contr` and `contr-data`, and the files and command-line tools in `%LOCALAPPDATA%\Contr`.

## Known limitations

- The installer, the app and the core are not code-signed yet. Windows SmartScreen warns before Setup runs (choose
  **More info**, then **Run anyway**), and Smart App Control, when it is on, may block them. Check the download as
  above first.
- Contr doesn't update itself yet. When Settings › Updates shows a newer release, download it from its release page.
- The engine's CPU, memory and disk limits can't be changed yet.
- Published UDP ports still depend on WSL's localhost forwarding.
- Builds are for x64 only.
- Installing WSL downloads it from Microsoft.
